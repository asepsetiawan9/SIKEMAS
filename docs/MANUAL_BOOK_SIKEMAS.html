BAB 1 — Pendahuluan

1.1 Tentang SIMPEL KAN

SIMPEL KAN (Sistem Pencetakan Pelaporan Pembelanjaan Kecamatan) adalah aplikasi berbasis web yang dirancang khusus untuk membantu proses pengelolaan keuangan dan aset di lingkungan Kecamatan Caringin, Kabupaten Garut.

Sistem ini mencakup beberapa modul utama:

Modul Fungsi
SPJ Digital Pengajuan, konsolidasi, dan verifikasi Surat Pertanggungjawaban keuangan secara digital
Kegiatan Anggaran Pengelolaan data kegiatan dan pagu anggaran per tahun
Aset / BMD Pencatatan, monitoring kondisi, QR Code, dan dokumen KIB/KIR aset milik daerah
Laporan Rekap realisasi anggaran dengan fitur export PDF dan Excel
Notifikasi Pemberitahuan real-time untuk setiap aksi penting dalam sistem
Dashboard Ringkasan eksekutif keuangan dan aset sesuai peran pengguna

1.2 Tujuan Manual Book

Manual book ini disusun untuk memberikan panduan lengkap dan detail kepada seluruh pengguna sistem SIMPEL KAN, agar:

  • Pengguna memahami fungsi dan fitur dari setiap modul
  • Pengguna dapat mengoperasikan sistem secara mandiri
  • Meminimalkan kesalahan operasional dalam penggunaan sistem
  • Menjadi referensi jika terdapat kendala teknis saat menggunakan aplikasi

1.3 Peran Pengguna (Role)

SIMPEL KAN memiliki 5 peran pengguna utama dengan hak akses yang berbeda-beda:

No Peran (Role) Deskripsi Modul yang Diakses
1 Staf Kasubag Umum Mengelola data kondisi dan lokasi aset Aset
2 Staf Keuangan Mengelola keuangan, konsolidasi SPJ, input aset, kelola kegiatan Dashboard, SPJ, Kegiatan, Aset, Laporan
3 Kasi (Kepala Seksi) Mengajukan SPJ untuk kegiatan di seksinya (5 seksi) Dashboard Kasi, Pengajuan SPJ
4 Sekmat (Sekretaris Kecamatan) Memverifikasi/menolak SPJ, monitoring seluruh data Dashboard, Verifikasi SPJ, Kegiatan, Aset, Laporan
5 Camat Melihat ringkasan eksekutif (read-only) Dashboard Eksekutif
ℹ️ Catatan: Setiap pengguna hanya akan melihat menu sidebar sesuai dengan peran (role) yang diberikan oleh Administrator Sistem. Menu yang tidak relevan dengan peran tidak akan ditampilkan.

1.4 Kebutuhan Sistem

Untuk mengakses SIMPEL KAN, pengguna memerlukan:

Kebutuhan Keterangan
Browser Google Chrome (direkomendasikan), Mozilla Firefox, atau Microsoft Edge versi terbaru
Koneksi Internet Stabil, minimal 1 Mbps
Resolusi Layar Minimal 1366×768 piksel (laptop/desktop)
Akun Email dan password yang telah didaftarkan oleh Administrator
URL Aplikasi https://sikemas.initd.web.id

BAB 2 — Login & Autentikasi

2.1 Cara Login ke Sistem

Untuk masuk ke sistem SIMPEL KAN, ikuti langkah-langkah berikut:

  1. Buka browser (Google Chrome direkomendasikan) dan akses alamat: https://sikemas.initd.web.id
  2. Halaman Login akan tampil seperti gambar di bawah ini.
  3. Masukkan Alamat Email yang telah didaftarkan pada kolom email.
  4. Masukkan Password pada kolom password.
  5. Centang opsi "Ingat Saya" jika ingin tetap login (opsional).
  6. Klik tombol "Masuk ke Sistem" berwarna biru.
  7. Jika berhasil, Anda akan diarahkan ke Dashboard sesuai peran Anda.
Gambar 2.1 — Halaman Login SIMPEL KAN
⚠️ Perhatian: Jika Anda salah memasukkan password sebanyak 5 kali berturut-turut, akun Anda akan dikunci sementara selama 1 menit. Pastikan Anda memasukkan email dan password dengan benar.
🔒 Keamanan: Jangan pernah membagikan email dan password Anda kepada orang lain. Jika lupa password, hubungi Administrator Sistem untuk melakukan reset password.

2.2 Logout dari Sistem

Untuk keluar dari sistem SIMPEL KAN:

  1. Klik pada nama pengguna atau ikon profil di pojok kanan atas halaman (area Topbar).
  2. Akan muncul dropdown menu. Klik opsi "Keluar Sistem".
  3. Anda akan diarahkan kembali ke halaman Login.
ℹ️ Tips: Selalu logout setelah selesai menggunakan sistem, terutama jika menggunakan komputer bersama (shared computer) untuk menjaga keamanan data.

BAB 3 — Dashboard

Dashboard adalah halaman utama yang tampil setelah pengguna berhasil login. Tampilan dashboard berbeda-beda sesuai peran pengguna. Dashboard menyajikan ringkasan data keuangan dan aset secara visual menggunakan kartu statistik dan grafik interaktif.

3.1 Dashboard Staf Keuangan / Sekmat

Dashboard untuk Staf Keuangan dan Sekmat menampilkan informasi operasional yang komprehensif, meliputi:

  • Kartu Statistik: Total Pagu Anggaran, Total Realisasi, Sisa Anggaran, dan Jumlah SPJ
  • Grafik Realisasi: Grafik batang perbandingan realisasi per kegiatan
  • SPJ Terbaru: Daftar SPJ terbaru yang masuk untuk ditindaklanjuti
  • Peringatan Pagu: Notifikasi visual jika ada kegiatan yang realisasinya mendekati atau melebihi 80% pagu
Gambar 3.1 — Dashboard Staf Keuangan / Sekmat

Penjelasan Elemen Dashboard:

Elemen Keterangan
Total Pagu Jumlah seluruh pagu anggaran dari semua kegiatan yang aktif pada tahun berjalan
Realisasi Jumlah total SPJ yang sudah berstatus "Diverifikasi" (sudah sah)
Sisa Anggaran Selisih antara Total Pagu dan Realisasi
Jumlah SPJ Total SPJ yang telah diajukan dalam sistem
Grafik Visualisasi perbandingan Pagu vs Realisasi per kegiatan dalam bentuk chart

3.2 Dashboard Kasi (Kepala Seksi)

Dashboard Kasi menampilkan ringkasan khusus untuk kegiatan dan SPJ milik seksi yang bersangkutan. Kasi hanya dapat melihat data kegiatan yang ditugaskan kepada seksinya sendiri.

Gambar 3.2 — Dashboard Kasi

Informasi yang Ditampilkan:

  • Total Kegiatan Saya: Jumlah kegiatan yang ditugaskan ke seksi Kasi
  • Total Pengajuan: Jumlah SPJ yang sudah pernah diajukan
  • SPJ Diverifikasi: Jumlah SPJ yang sudah diverifikasi (disetujui)
  • SPJ Ditolak: Jumlah SPJ yang ditolak dan perlu ditindaklanjuti
  • Daftar Kegiatan: Tabel kegiatan beserta pagu dan sisa anggaran masing-masing
  • Riwayat SPJ Terbaru: Daftar SPJ terbaru beserta status terkininya

3.3 Dashboard Sekmat (Verifikasi)

Dashboard Sekmat memiliki tampilan serupa dengan Dashboard Staf Keuangan, namun dengan penekanan pada jumlah SPJ yang menunggu verifikasi. Di sidebar, Sekmat akan melihat badge (angka) yang menunjukkan berapa SPJ yang perlu diverifikasi.

BAB 4 — Modul SPJ Digital

Modul SPJ Digital adalah modul utama dalam SIMPEL KAN yang menangani seluruh alur pengajuan Surat Pertanggungjawaban (SPJ) keuangan, mulai dari pengajuan oleh Kasi, konsolidasi oleh Staf Keuangan, hingga verifikasi akhir oleh Sekretaris Kecamatan (Sekmat).

Penjelasan Warna Status:

Status Warna Badge Keterangan

4.2 Pengajuan SPJ Baru (Kasi)

Fitur ini digunakan oleh Kasi (Kepala Seksi) untuk membuat pengajuan SPJ baru. Kasi hanya dapat mengajukan SPJ untuk kegiatan yang ditugaskan kepada seksinya.

Langkah-langkah Pengajuan SPJ:

  1. Login sebagai Kasi, kemudian klik menu "Pengajuan SPJ" di sidebar kiri.
  2. Pada halaman daftar SPJ, klik tombol "+ Buat Pengajuan Baru" di pojok kanan atas.
  3. Isi formulir pengajuan SPJ dengan lengkap (lihat gambar di bawah).
  4. Pilih Kegiatan dari dropdown — hanya kegiatan milik seksi Anda yang tampil.
  5. Sistem akan menampilkan Sisa Pagu kegiatan secara real-time di bawah dropdown.
  6. Masukkan Nominal pengajuan (tidak boleh melebihi sisa pagu).
  7. Pilih Periode Bulan dan Tahun SPJ.
  8. Isi Jenis Belanja (contoh: Belanja ATK, Belanja Perjalanan Dinas, dll).
  9. Upload File Bukti (format: JPG, PNG, atau PDF, maksimal 5 MB).
  10. Klik tombol "Ajukan SPJ" untuk mengirim pengajuan.
Gambar 4.1 — Formulir Pengajuan SPJ Baru (Kasi)
⚠️ Aturan Bisnis Penting:
  • Nominal pengajuan tidak boleh melebihi sisa pagu kegiatan.
  • Kasi tidak bisa membuat pengajuan baru jika masih ada SPJ yang berstatus Ditolak dan belum ditindaklanjuti.
  • Satu kegiatan bisa memiliki banyak SPJ (partial spending diperbolehkan).
  • Kegiatan dengan status "Selesai" atau "Dibatalkan" tidak bisa menerima SPJ baru.

4.3 Konsolidasi SPJ (Staf Keuangan)

Setelah Kasi mengajukan SPJ, Staf Keuangan bertugas melakukan konsolidasi. Konsolidasi adalah proses verifikasi awal dan penetapan nomor SPJ resmi.

Langkah-langkah Konsolidasi:

  1. Login sebagai Staf Keuangan, klik menu "SPJ" di sidebar.
  2. Halaman Konsolidasi akan menampilkan daftar SPJ yang masuk dari semua Kasi.
  3. Klik tombol "Lihat Detail" (ikon mata) pada SPJ yang ingin diproses.
  4. Periksa informasi pengajuan: kegiatan, nominal, file bukti, dan kelengkapan data.
  5. Klik tombol "Konsolidasi" untuk memproses SPJ. Sistem akan otomatis:
    • Membuat Nomor SPJ otomatis (format: SPJ/SEKSI/BULAN/TAHUN/URUT)
    • Mengubah status menjadi Dikonsolidasi
  6. Setelah dikonsolidasi, klik "Ajukan ke Sekmat" untuk mengirim SPJ ke tahap verifikasi.
Gambar 4.3 — Halaman Konsolidasi SPJ (Staf Keuangan)
ℹ️ Format Nomor SPJ Otomatis: SPJ/{NAMA_SEKSI}/{BULAN_ROMAWI}/{TAHUN}/{NOMOR_URUT}
Contoh: SPJ/PEMERINTAHAN/IX/2026/001

4.4 Verifikasi SPJ (Sekmat)

Sekretaris Kecamatan (Sekmat) memiliki wewenang untuk memverifikasi (menyetujui) atau menolak SPJ yang telah diajukan oleh Staf Keuangan.

Langkah-langkah Verifikasi:

  1. Login sebagai Sekmat, klik menu "Verifikasi SPJ" di sidebar (perhatikan badge angka yang menunjukkan jumlah SPJ menunggu).
  2. Halaman akan menampilkan Antrean Verifikasi — daftar SPJ yang statusnya Diajukan Verifikasi.
  3. Klik tombol "Lihat Detail" pada SPJ yang ingin diverifikasi.
  4. Periksa semua informasi SPJ: data kegiatan, nominal, bukti fisik, nomor SPJ, dll.
  5. Pilih salah satu aksi:
    • ✅ Verifikasi (Setujui): SPJ dinyatakan sah, status berubah menjadi Diverifikasi
    • ❌ Tolak: SPJ ditolak. Wajib mengisi catatan penolakan (minimal 10 karakter).
Gambar 4.4 — Halaman Verifikasi SPJ (Sekmat)
🔒 Penting: SPJ yang sudah berstatus Diverifikasi bersifat FINAL dan IMMUTABLE — tidak bisa diubah atau dihapus oleh siapapun. Pastikan verifikasi dilakukan dengan teliti.

4.5 Arsip SPJ

Halaman Arsip SPJ menampilkan seluruh riwayat SPJ dalam bentuk tabel dengan fitur filter dan pencarian. Semua peran dapat mengakses arsip ini (dengan batasan sesuai hak akses masing-masing).

Fitur Filter yang Tersedia:

Filter Keterangan
Status Filter berdasarkan status SPJ (Draft, Diajukan, Dikonsolidasi, dll)
Kegiatan Filter berdasarkan nama kegiatan anggaran
Bulan Filter berdasarkan periode bulan SPJ
Tahun Filter berdasarkan tahun anggaran
Pencarian Cari berdasarkan nomor SPJ atau nama kegiatan

4.6 Detail SPJ

Halaman detail SPJ menampilkan seluruh informasi lengkap tentang satu SPJ, termasuk:

  • Informasi pengajuan (kegiatan, nominal, jenis belanja, periode)
  • Status terkini dan timeline perubahan status
  • Data penanggung jawab di setiap tahap (pengaju, konsolidator, verifikator)
  • Preview file bukti yang diupload
  • Catatan verifikasi (jika ada penolakan)
  • Nomor SPJ resmi (setelah dikonsolidasi)

BAB 5 — Modul Kegiatan Anggaran

Modul Kegiatan Anggaran digunakan oleh Staf Keuangan untuk mengelola data kegiatan dan pagu anggaran. Kegiatan inilah yang nantinya menjadi dasar pengajuan SPJ oleh Kasi.

5.1 Daftar Kegiatan

Halaman ini menampilkan seluruh kegiatan yang terdaftar dalam tahun anggaran berjalan, lengkap dengan informasi pagu, realisasi, dan sisa anggaran masing-masing kegiatan.

Gambar 5.1 — Halaman Daftar Kegiatan Anggaran

Kolom Informasi pada Tabel:

Kolom Keterangan
Nama Kegiatan Nama kegiatan anggaran
Kode Rekening Kode rekening anggaran kegiatan
Pagu Jumlah anggaran yang dialokasikan (dalam Rupiah)
Realisasi Jumlah anggaran yang sudah terpakai (SPJ diverifikasi)
Sisa Pagu dikurangi Realisasi
Kasi Kepala Seksi yang bertanggung jawab atas kegiatan
Sumber Dana Sumber pendanaan (APBD, DAU, DAK, BHP, ADD, Lainnya)
Status Aktif, Selesai, atau Dibatalkan

5.2 Tambah Kegiatan Baru

Untuk menambahkan kegiatan anggaran baru (hanya Staf Keuangan):

  1. Pada halaman Daftar Kegiatan, klik tombol "+ Tambah Kegiatan".
  2. Akan muncul modal/formulir pengisian. Isi data berikut:
    • Nama Kegiatan — Nama lengkap kegiatan anggaran
    • Kode Rekening — Kode rekening sesuai APBD
    • Pagu Anggaran — Jumlah anggaran (dalam Rupiah)
    • Sumber Dana — Pilih dari dropdown (APBD, DAU, DAK, dll)
    • Kasi Penanggung Jawab — Pilih Kasi dari dropdown
    • Periode Mulai & Selesai — Rentang waktu kegiatan (opsional)
    • Deskripsi — Keterangan tambahan (opsional)
  3. Klik tombol "Simpan" untuk menyimpan kegiatan baru.

5.3 Edit & Hapus Kegiatan

Untuk mengedit kegiatan:

  1. Klik ikon edit (pensil) pada baris kegiatan yang ingin diubah.
  2. Modal edit akan muncul dengan data kegiatan yang sudah terisi.
  3. Ubah data yang diperlukan, lalu klik "Simpan Perubahan".
⚠️ Perhatian: Kegiatan yang sudah memiliki SPJ tidak bisa dihapus untuk menjaga integritas data keuangan. Sebagai gantinya, ubah status kegiatan menjadi "Selesai" atau "Dibatalkan".

6.2 Tambah Aset Baru

  5. Sistem akan otomatis:

6.4 QR Code & KIB/KIR

Setiap aset memiliki QR Code yang bisa diunduh dan dicetak untuk ditempel pada aset fisik.

Cara Mengunduh QR Code:

  1. Buka halaman Detail Aset atau pada daftar aset klik ikon QR.
  2. Klik tombol "Download QR Code".
  3. File gambar QR Code akan terunduh dan siap dicetak.

Cara Generate Dokumen KIB/KIR:

  1. Buka halaman Detail Aset.
  2. Klik tombol "Generate KIB/KIR" (hanya Staf Keuangan).
  3. Sistem akan otomatis menentukan jenis dokumen (KIB untuk aset tetap, KIR untuk persediaan).
  4. Dokumen PDF akan di-generate dan bisa diunduh.
ℹ️ Perbedaan KIB dan KIR:
  • KIB (Kartu Inventaris Barang): Untuk aset tetap — tanah, bangunan, kendaraan, peralatan mesin
  • KIR (Kartu Inventaris Ruangan): Untuk barang habis pakai dan persediaan

BAB 7 — Modul Laporan

Modul Laporan menyediakan rekap data keuangan dalam bentuk tabel dan grafik, serta fitur export ke format PDF dan Excel. Modul ini dapat diakses oleh Staf Keuangan, Sekmat, dan Camat.

7.1 Halaman Laporan

Halaman laporan menampilkan ringkasan realisasi anggaran per kegiatan dengan filter tahun anggaran.

Gambar 7.1 — Halaman Laporan Realisasi Anggaran

Informasi yang Ditampilkan:

  • Tabel rekapitulasi per kegiatan (nama, pagu, realisasi, sisa, persentase)
  • Total keseluruhan anggaran, realisasi, dan sisa
  • Visualisasi grafik perbandingan pagu vs realisasi
  • Filter berdasarkan tahun anggaran

7.2 Export PDF & Excel

Data laporan dapat di-export ke format PDF dan Excel untuk keperluan cetak dan pelaporan.

Cara Export Laporan:

  1. Buka halaman Laporan dari menu sidebar.
  2. Pilih tahun anggaran yang ingin dilaporkan (jika tersedia filter).
  3. Untuk export PDF, klik tombol "Export PDF" — dokumen PDF akan langsung terunduh.
  4. Untuk export Excel, klik tombol "Export Excel" — file XLSX akan langsung terunduh.
ℹ️ Catatan: File export berisi data realisasi per kegiatan, termasuk total keseluruhan. Format PDF cocok untuk pelaporan formal, sedangkan Excel cocok untuk analisis data lebih lanjut.

BAB 8 — Notifikasi

Sistem notifikasi SIMPEL KAN memberikan pemberitahuan kepada pengguna secara otomatis setiap kali terjadi aksi penting yang relevan dengan peran mereka.

8.1 Pusat Notifikasi

Notifikasi dapat diakses melalui dua cara:

  • Ikon Lonceng (Bell) di Topbar: Klik ikon lonceng di pojok kanan atas untuk melihat 10 notifikasi terbaru secara cepat. Angka badge menunjukkan jumlah notifikasi yang belum dibaca.
  • Halaman Pusat Notifikasi: Klik "Lihat Semua" atau menu sidebar untuk melihat seluruh riwayat notifikasi.
Gambar 8.1 — Halaman Pusat Notifikasi

Cara Mengelola Notifikasi:

  1. Membaca notifikasi: Klik pada baris notifikasi — Anda akan diarahkan ke halaman terkait dan notifikasi otomatis ditandai "dibaca".
  2. Tandai semua dibaca: Klik tombol "Tandai Semua Dibaca" untuk menghapus badge notifikasi.

8.2 Jenis Notifikasi

BAB 9 — Profil Pengguna

Setiap pengguna SIMPEL KAN dapat mengelola data profil dan mengubah password melalui halaman profil.

9.1 Edit Profil

Untuk mengubah data profil:

  1. Klik nama pengguna di pojok kanan atas (Topbar), kemudian pilih "Profil".
  2. Halaman profil akan menampilkan informasi akun Anda.
  3. Ubah data yang ingin diperbarui (Nama, Email).
  4. Klik tombol "Simpan" untuk menyimpan perubahan.
Gambar 9.1 — Halaman Edit Profil Pengguna

9.2 Ubah Password

Untuk mengubah password:

  1. Pada halaman Profil, scroll ke bagian "Ubah Password".
  2. Masukkan Password Lama (password saat ini).
  3. Masukkan Password Baru.
  4. Masukkan lagi Konfirmasi Password Baru.
  5. Klik tombol "Ubah Password".
⚠️ Tips Keamanan Password:
  • Gunakan password minimal 8 karakter
  • Kombinasikan huruf besar, huruf kecil, angka, dan simbol
  • Jangan gunakan password yang sama dengan akun lain
  • Ganti password secara berkala (minimal 3 bulan sekali)

10.5 Troubleshooting (Penanganan Masalah)

Masalah Penyebab Solusi
Tidak bisa login Email/password salah, atau akun dinonaktifkan Periksa email dan password. Jika tetap gagal, hubungi Administrator.
Akun terkunci Terlalu banyak percobaan login (5x gagal) Tunggu 1 menit, kemudian coba lagi dengan password yang benar.
Tidak bisa ajukan SPJ Sisa pagu tidak cukup, atau ada SPJ ditolak yang belum ditindaklanjuti Periksa sisa pagu kegiatan. Selesaikan SPJ yang berstatus "Ditolak" terlebih dahulu.
File bukti gagal upload Ukuran file melebihi 5 MB, atau format tidak didukung Kompres file atau konversi ke format JPG/PNG/PDF dengan ukuran < 5 MB.
Menu tidak muncul Role pengguna tidak memiliki hak akses ke menu tersebut Menu ditampilkan sesuai peran. Hubungi Administrator jika ada kekeliruan role.
Halaman error 403 Mencoba mengakses halaman yang tidak diizinkan Gunakan menu sidebar untuk navigasi. Jangan mengubah URL secara manual.
Data tidak ter-update Cache browser Tekan Ctrl+Shift+R untuk hard refresh halaman.
